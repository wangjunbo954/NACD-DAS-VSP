# NACD: DAS-VSP Denoising Under Limited Data

Project page for **Transferring Visual Priors for DAS-VSP Data Denoising: A Dual-Branch Modulation Framework Under Limited Data**.

NACD combines a frozen CLIP visual encoder, a Noise Domain Encoder (NDE), and Domain-Adaptive Squeeze-Excitation (DASE) modules for DAS-VSP denoising with limited paired training data.

## Current status

This repository currently contains this README only. Source code, the demonstration, and test data have not yet been released.

The method is being applied in an ongoing pilot exploration project at an oil and gas exploration company whose identity remains confidential. Results from this project are not included in the current manuscript.
